# shatter-intro: character fracture

`fracture_character.py` splits a character GLB into face-owned Voronoi shards for the shatter/reassemble intro. Each source triangle goes to the nearest of N area-weighted seed triangles (no booleans, so reassembly is exact); every shard is one glTF node with its origin at the shard vertex centroid, original UVs and material names preserved, and custom props `shard_index` and `shard_order` (centroid height normalized 0..1 across shards, bottom first; exported via `export_extras`). Multiple source meshes are joined first; non-mesh nodes are dropped. Run with Blender: `blender -b --python fracture_character.py -- IN.glb OUT.glb --shards 300 --seed 7`, or with the bpy module: `<bvenv>/bin/python fracture_character.py -- IN.glb OUT.glb --shards 300 --seed 7`. Tests (use only a generated fixture, never a real asset): `uv pip install --python <bvenv>/bin/python pytest` then `<bvenv>/bin/python -m pytest blender/shatter-intro/tests -q` (bvenv = Python 3.11 venv with `bpy==5.0.1`).
